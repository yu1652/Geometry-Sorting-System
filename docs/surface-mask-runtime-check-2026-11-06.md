# 表面掩膜运行接入复核

本次补齐旧版识别中表面掩膜的实际用途：输入修正、目标关联、颜色取样、表面框收紧及内孔候选显示。类别仍来自旧 26 类 YOLO；二值 UNet 没有独立类别输出，不以孔洞数硬改形状。

## 输入依据

检查提供数据的 `tools/train_mask_unet.py`：训练时读取半图文件，转 RGB、320×320、float32 /255。实际训练样本是处理后的青色特征图，不能因脚本出现 RGB 就误认为训练输入是原彩色照片。旧接入向它输入原彩色半图，存在内容分布不匹配。

当前实时输入：原帧中心裁剪 → 双摄特征拼图 → YOLO 张量 → 取未补边的特征半图给掩膜。张量顺序与保存特征半图加载后的 RGB 保持一致。颜色只采原帧中由掩膜选中的像素。特征文件输入不产生颜色结果。

## 本地真实权重检查

- 使用提供的 `surface_mask.onnx`，CPU ONNX Runtime，输出 logits 大于 0 即前景。
- 在已有 acceptance20 的 20 张图上检查输出，像素平均 IoU 约 0.742。这 20 张曾参与该模型训练，不能作为独立验证指标，更不能作为形状分类准确率。
- 其中 8 张环柱样本有的漏掉人工标出的孔，也有的多出孔。因此当前孔候选仅供人工检查，不是可靠类别纠错器。
- 提供的 `000002_combined.jpg` 用真实 SHAPE ONNX 和表面 ONNX 联合运行：类别 `yuan_zhu`，左右覆膜均成功关联，内孔候选均为 0，特征图未生成虚假颜色。该运行验证管线连通性，不证明实机分类精度提升。

## 仍需板端验证

用同一批实物、相同相机和光照，记录有／无覆膜的类别、颜色、失败、左右掩膜及耗时。分别统计形状准确率和掩膜质量。特别核对环件孔洞、孔内壁、阴影、透明背景和无目标场景；未达到要求时需修正标注或训练模型，再重新比较。
