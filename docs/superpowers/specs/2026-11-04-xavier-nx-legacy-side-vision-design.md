# Xavier NX 双摄识别设计

日期 2026-11-04。首版沿用旧版双摄拼接识别，并加入基于 COCO 实例掩膜的表面覆膜。本文范围是识别区形状与颜色识别、表面覆膜、模型更换入口及其验收。

## 识别流程

1. 取得同一物块的左、右轴测原始彩色帧。沿用旧版的视图顺序和中心裁剪方式，每路用 `INTER_AREA` 缩放至 `320×320`，左图在前、右图在后，横拼成 `640×320`。
2. 从整张拼接图生成普通灰度、CLAHE 增强灰度和 Canny 边缘。CLAHE 的裁剪限制为 `2.0`，网格 `8×8`。Canny 使用 `5×5` 高斯模糊后的灰度图，阈值为 `60/160`。
3. 按旧版方式合并通道，上下各补 `160` 像素、填充值 `114`。模型实际通道顺序为 `[edge, gray_clahe, gray]`，归一化到 `0–1`。形状模型每对图推理一次。
4. 按旧版的置信度 `0.45`、按类别 NMS IoU `0.50` 作为初始参数。保留旧版按最高检测置信度选形状的规则。跨拼接线的框按左右重叠面积择侧，相同面积归左。把检测框映射回对应彩色视图，用原始彩色区域做 HSV，颜色优先选有结果的视图，再比颜色置信度。调试页显示左右原图、拼接检测图以及类别、颜色、置信度和失败原因。

## YOLO 框与 COCO 覆膜

- 用未画框、未灰度化、未补边的 `640×320` 彩色拼接图作为标注底图。先为左右视图中可见的物块各标一个 YOLO 检测矩形，再在同一张图上为每个实例标可见表面。检测 TXT 和 COCO JSON 按图像和实例对应，左右同一物块保留配对关系。
- COCO 实例掩膜以整张拼接图保存，RLE 尺寸为 `[320,640]`（高、宽），框和面积可从掩膜计算。把可见物体表面和孔内壁标为前景，通孔中露出的背景、投影和遮挡物保留为背景。划分训练、验证、测试时，同一实物的配对图和同一次连拍放在同一组。掩膜格式以 [COCO 官方 API](https://github.com/cocodataset/cocoapi/blob/master/PythonAPI/pycocotools/coco.py#L384-L411) 的解码行为为验收依据。
- 旧 `SHAPE.onnx` 输出形状和矩形框。独立表面分割模型使用从 COCO 标注裁出的左右彩色半图及其掩膜训练，运行时按原彩色半图分别推理，与同侧检测框关联。右图局部坐标加 `320` 像素后还原到拼接图。先撤销检测补边，再让原图、框和掩膜共用显示变换。调试页将有效掩膜半透明叠加，并保留矩形框。颜色判定使用原始像素。
- 现有 `surface_mask.onnx` 可作为单视图离线试跑基线，需用新场景验证轮廓、通孔和左右对齐后才能启用。覆膜验收使用人工复核的 COCO 掩膜。模型缺失、无有效掩膜或关联不明确时显示覆膜状态，保留独立的检测框结果。

## 模型与换模入口

- 首版侧视模型来源为旧程序的 `weights/SHAPE.onnx`，SHA-256 为 `54c39dfece119797ac9a30f8aa70395297940f25400a636d025572bcb88a0ece`。模型有 26 类，输入 `1×3×640×640`，原始输出 `1×30×8400`。类别 ID 以 ONNX 内嵌的 26 类顺序为准。旧 `label_reference.yaml` 只有 21 项且顺序不同。以旧训练资料中的 26 类表作为中文名初稿，经过实物核对后生成独立的中文名和箱号绑定。未确认的类别不发分箱命令。
- 在目标 Xavier NX 上为该模型构建适配本机 TensorRT 的 FP16 Engine，使用保存的双摄样本核对 TensorRT 与旧 ONNX 流程的结果。预处理参数、类别顺序和后处理规则随模型版本一起保存。
- 调试页提供「模型管理 → 更换侧视模型」。首版接收兼容同一拼接识别流程的模型包，包内声明模型版本、输入输出、预处理和有序类别表。设备安全停机后导入、校验并试跑样本，确认后启用。失败时保留当前版本，提供回退入口。更换后重新核对分箱绑定。
- 表面掩膜模型在模型管理中单独导入、试跑、启用和回退。导入时核对其彩色半图输入和掩膜输出，保持覆膜结果和形状检测结果可分别检查。
- 新版 23 类单图模型后续另行处理。未来接入时按其训练输入实现对应的适配，再扩展换模入口。

## 顶视与机械接口

顶部相机使用独立的 `tray_object_detector.onnx` 查找托盘中的 `object`，经九点标定输出 XY 定位结果。它与侧视分别配置和替换，侧视负责形状与颜色。视觉模块只返回检测结果，自动分箱由控制器在有效识别结果、箱号绑定和机械状态均满足时下发。

## 验收顺序

1. 用同一批已标注左右样本比较旧程序与 Xavier NX 实现的预处理图、原始类别 ID、颜色和框坐标。用人工标注核对中文显示名。样本覆盖空画面、跨拼接线、相似形状、遮挡和需要分拣的类别。
2. 在板端用实物完成只识别测试，按物块记录正确、错误和无结果，核对耗时。确认类别和箱号的对应后再联动分拣。
3. 验证更换模型时对损坏包、输入输出不匹配和类别顺序不符的拒绝行为，以及试跑失败后当前模型仍可用、回退后版本与分箱规则一致。
4. 在左右视图分别验收掩膜位置和表面边缘，检查右侧偏移、轮廓出界、通孔是否填死、空画面是否误覆膜。确认换模失败时仍能显示有效检测结果。
