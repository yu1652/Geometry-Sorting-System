# Xavier NX 整机仿真与设备接口 Implementation Plan

**目标** 在不连接机械的情况下演示三路取图、顶部定位、九点标定、ESP32 模拟消息和比赛计数。继续使用旧版双摄识别程序作为正式离线验证入口。现场设备按各自的验收清单再接入。

**约束** Python 3.8、Qt5/Qt6。实机串口与执行器默认禁止，仿真输出明确标识，示例标定和软限位只供仿真。保留现有固件与模型、旧回放程序的启动方式。按模块测试和独立复核，上传到现有开发分支。

1. **相机服务** 新增 `jetson-app/camera_service.py` 和对应单测。角色为 `left/right/top`，按配置选择稳定设备路径或录像，独立读取、关闭和错误报告。`CameraSource(source, capture_factory=None)` 提供 `open/read/close`，`CameraService(sources)` 按角色提供 `open/read/close`。用 fake capture 验证路径、丢帧、复制和释放。
2. **九点标定和顶部定位** 新增 `jetson-app/xy_calibration.py`、`jetson-app/tray_locator.py` 与单测。标定基于 P1–P9 拟合二次映射、提供拟合误差、限定像素有效区与机械范围。定位从顶部 ROI 解码单类检测，选择机械 X 最小的物块，按检测框右边中点换算，并单独检查推板偏移后坐标。验证退化点、出界、无目标、舍入。提供已验证结构的独立 TensorRT 合同 `[1,3,640,640]→[1,5,8400]`。真实权重单独部署。
3. **模拟 ESP32** 新增 `jetson-app/sorter_simulation.py` 与单测。复用旧工程协议的状态和消息语义。手动确认零点后才能开始仿真、维护动作受状态限制、收到匹配的 `DONE` 只计数一次、超时和重启清除待处理状态。先做纯代码模拟，真实串口握手与运动不在此入口启用。
4. **仿真界面** 新增 `jetson-app/sorter_console.py`。调试页显示左、右、顶部、日志，比赛页显示最近分拣及六箱计数，调试页进入九点标定并模拟 GOTO 和推板升降。为旧入口增加显式仿真选项或提供独立命令。用 Qt5/Qt6 无显示测试切页、运行一次模拟周期、原点门禁和保存标定。
5. **启动与交接** 给 Jetson 用户图形会话提供手动安装的自动启动配置，默认打开现有离线操作台；文档区分仿真和实机。板子到场后验收摄像头、俯拍模型、实际机械安全范围与原点、真实串口及持续分拣，再调整开机默认行为。
