# Xavier NX Linux 20261107

在现有 `jetson-app` 目录里更新。更新包包含 20261107 发布版的两个 ONNX 模型，放在 `models/linux_20261107/`。

```bash
bash deploy/build_models.sh --linux-20261107
bash run_jetson.sh --linux-20261107
```

首次在板上构建两个 TensorRT FP16 引擎。离线验证可执行 `bash run_jetson.sh --linux-20261107 --offline`。省略新版参数可启动原来的 26 类模式。

新版使用原模型的八类顺序、灰度／CLAHE／边缘特征、形状检测阈值 0.45、托盘检测阈值 0.35、中心 60% 取色区域、五批新帧、三次识别复核和五秒扫描时限。托盘 ROI 是 `(16, 0, 519, 479)`，推料固定偏移为 `(1, 0)` 毫米。位置补偿按发布包四个端点作有界线性插值，最终目标须在新版取料范围内（X 43.563–226.331、Y 0.125–164.027 毫米）。拼接、颜色像素过滤和补偿实现根据可见配置重建，板端相机画面需要核对。

程序默认打开比赛页，可以切换卡片、看板、六箱表格三种布局。比赛页的箱图取自已确认投放的物件侧视快照，当前进程内保留。调试页提供拼接检测、实际取色区域、托盘定位和三类日志。九点标定支持独立测试坐标、写回选中点、整组平移和撤销。

赛前切到调试页连接三路相机，等待两个模型完成试跑。确认当前相机下的九点坐标、检测区域和物理原点，清空识别区并采集空区参考，再连接串口运行。模型和本轮箱号分开保存，设备绑定、校准和空区参考继续使用现有数据。新版轮次记录为 `data/live_auto_bins_20261107.json`。包内 `imports/linux_20261107_xy_calibration.yaml` 是 Windows 发布版的标定参考。

发送投箱后等待 `DONE` 的时限为 5 秒。收到 `DONE` 后，上位机暂缓回复新的推料请求，连续三次确认识别区为空才计数并恢复推料。最多检查五次，仍不能确认清空时停止进料并保留诊断。确认投放 12 件后结束本轮。确认推空时重新定位，未识别到有效类别且无法确认空区时停机。暂停会完成本件后暂停进料，继续时等新的推料请求。停止会释放电机，恢复前需手动对零。默认按确认的形状和颜色依次绑定六箱。

本模式配套仓库中 Y 轴 39 脉冲/mm 的 ESP32 0.1.0 固件。沿用 X 轴 40 脉冲/mm、推料终止线 X=10 mm、等待点 (49, 5) mm 和原舵机配置。已在运行该固件的设备可以直接更新上位机。若已经烧录之前的 0.1.1，需刷回本包的 0.1.0，上位机会拒绝使用错误的固件版本。Windows 发布包的插件执行逻辑、第七类纠偏、NG 处理、拨料协议和界面主题没有在本次移植中复刻。比赛兜底箱的行为需要明确后才能接入。诊断包和板端逐件验证可用于比对识别、定位及动作时序。
